# ADR-0001: Adopción de Spec-Driven Development (SDD) y Docs-as-Code

* **Estado:** Aceptado
* **Fecha:** 2026-08-11

---

## Contexto
El ecosistema RestoCore involucra frentes de trabajo paralelos. Para evitar ambigüedades y alucinaciones de API, se adopta SDD y Docs-as-Code.

---

## Decisión
La especificación en `RestoCore-Docs` es la Única Fuente de Verdad (SSOT). Prohibido desarrollar código de aplicación sin contratos ni PRDs previamente aprobados.
