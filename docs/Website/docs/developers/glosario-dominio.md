# Glosario de Lenguaje Ubicuo (DDD)

Vocabulario técnico y de negocio unificado para el ecosistema RestoCore.

---

## Entidades Principales
* **Tenant:** Restaurante / Comercio suscrito a la plataforma multi-tenant.
* **Carta QR:** Interfaz pública de lectura del menú optimizada para < 2s LCP.
* **Categoría:** Agrupamiento jerárquico de la oferta gastronómica.
* **Plato:** Producto comercial con precio, alérgenos e imagen en SeaweedFS.
* **Modificador:** Opciones de personalización con deltas de precio.
* **Mesa / QR Table:** Ubicación física en salón con token único de seguridad (`table_token`).
