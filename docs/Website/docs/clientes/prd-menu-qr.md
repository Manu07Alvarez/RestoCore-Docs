# PRD: Carta QR Pública

Especificación de requerimientos para la interfaz pública de lectura de menús digitales.

---

## Resultados (Outcomes)
* Carga interactiva en < 2 segundos LCP en dispositivos móviles.
* Lectura clara de categorías, productos, modificadores y precios.

---

## Restricciones
* REST API (OpenAPI 3.1).
* Almacenamiento en caché CDN perimetral.
* Imágenes desacopladas en SeaweedFS.
